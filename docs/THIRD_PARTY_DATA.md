This reproducibility package is derived from:

**CIC-MalMem-2022**

Provider:
Canadian Institute for Cybersecurity (CIC),
University of New Brunswick (UNB), Canada.

Official dataset page:

https://www.unb.ca/cic/datasets/malmem-2022.html

Official CIC dataset policy:

https://www.unb.ca/cic/datasets/

## Original Dataset Citation

Tristan Carrier; Princy Victor; Ali Tekeoglu; Arash Habibi Lashkari

"Detecting Obfuscated Malware using Memory Feature Engineering"

8th International Conference on Information Systems Security and Privacy (ICISSP), 2022.

## CIC Redistribution Requirement

The Canadian Institute for Cybersecurity states on its official
dataset portal that CIC datasets may be redistributed, republished,
and mirrored, provided that use or redistribution includes citation
to the dataset and the associated research paper.

Users of this package should independently consult the current
official CIC dataset page and policy before redistributing original
CIC data.

## Ownership and Attribution

This package does NOT claim authorship or ownership of the original
CIC-MalMem-2022 dataset.

The original memory-analysis dataset remains attributable to its
original creators and the Canadian Institute for Cybersecurity.

## Contribution of This Package

The contribution of this research package consists of derived
research artifacts including:

- leakage-audited grouping and split manifests
- leakage-aware evaluation protocols
- binary malware-detection experiments
- four-class category experiments
- sixteen-class malware-family experiments
- nested model-fusion evaluation
- feature-selection experiments
- SHAP explainability analysis
- explanation-stability analysis
- prototype-guided model counterfactual analysis
- evidence-aware MITRE ATT&CK alignment
- statistical ATT&CK-support characterization
- calibration analysis
- reproducibility scripts
- SHA-256 provenance manifests
- release-readiness validation

## Scientific Terminology

This work should be described as:

"An enriched, leakage-audited, explainability- and ATT&CK-aligned
benchmark derived from CIC-MalMem-2022."

It should NOT be described as a newly collected malware dataset unless
new raw memory acquisitions are independently collected.
