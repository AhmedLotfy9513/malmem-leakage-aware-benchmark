# Data Availability Statement

The experiments in this project are based on the publicly available
CIC-MalMem-2022 dataset released by the Canadian Institute for
Cybersecurity at the University of New Brunswick.

Official source:

https://www.unb.ca/cic/datasets/malmem-2022.html

The present research provides an enriched reproducibility package
containing derived split manifests, evaluation protocols, benchmark
results, explainability artifacts, statistical analyses, ATT&CK-aligned
evidence artifacts, and integrity-validation metadata.

The original CIC-MalMem-2022 feature matrix is not required to be
embedded directly in this repository because users can obtain the
source dataset from the authoritative CIC distribution page.

A SHA-256 source-data fingerprint is included to support local source
identity verification.

The reproducibility package is intended to permit reconstruction and
verification of the reported experimental protocol while preserving
clear attribution to the original dataset creators.

A persistent repository DOI will be added after archival publication.
